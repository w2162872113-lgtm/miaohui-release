# MiaoHui 秒回 · 安装包下载

企业微信智能自动回复助手。

## 下载（Windows）

[点击下载 MiaoHui-Setup.exe](https://github.com/w2162872113-lgtm/miaohui-release/releases/latest/download/MiaoHui-Setup.exe)

不需要登录 GitHub，打开链接即可下载。

## 安装

1. 双击 `MiaoHui-Setup.exe`。
2. 如果出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
3. 按提示完成安装，桌面会出现 MiaoHui 图标。

新装的软件可以免费试用 3 天，之后需要输入授权码（向服务商获取）。
